# MiniGame Turtle: Movimento e Direção 🐢🎮

Este é um minigame interativo utilizando a biblioteca `turtle` do Python. O objetivo é controlar a movimentação de uma seta na tela, direcionando-a para frente ou para trás e ajustando sua direção com base nas entradas do usuário. O jogo permite que o usuário defina a direção (direita ou esquerda) e a distância de cada movimento, assim como o ângulo da rotação.

## Funcionalidades ⚙️

- **Movimento para frente ou para trás:** O jogador pode escolher entre mover a seta para frente ou para trás. ⬆️⬇️
- **Direção:** O jogador escolhe a direção (direita ou esquerda) para ajustar a orientação da seta. ↩️↪️
- **Distância e Ângulo:** O jogador define a distância que a seta deve percorrer e o ângulo da rotação antes de mover. 📏🔄
- **Loop de movimento:** O jogo continua até que o jogador escolha não continuar. 🔄

## Como Jogar 🕹️

1. O programa solicita que o jogador insira um comando para mover a tartaruga. 🐢
2. O jogador escolhe se deseja mover a tartaruga para **frente (F)** ou **para trás (T)**. ⬆️⬇️
3. Dependendo da escolha, o programa pedirá para escolher a direção (direita ou esquerda) e definir a distância e o ângulo de rotação. ↩️↪️
4. Após cada movimento, o jogador é perguntado se deseja continuar. Se a resposta for **'S'** (sim), o jogo continua; se for **'N'** (não), o jogo termina. ✅❌
